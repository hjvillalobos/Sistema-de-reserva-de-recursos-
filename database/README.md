# Base de datos del Proyecto II

Esta carpeta queda preparada para el script MySQL y los datos iniciales que
coordinará el compañero A. Todavía no contiene un esquema ni una conexión JDBC.

Workbench 8.0 CE se usará para administrar MySQL Server y ejecutar el script.
Solo `backend` deberá incorporar el conector JDBC y la configuración de conexión.
Las credenciales reales no se deben incluir en el repositorio.

El perfil `local` sigue utilizando los XML de `data/`, en la raíz del repositorio.
